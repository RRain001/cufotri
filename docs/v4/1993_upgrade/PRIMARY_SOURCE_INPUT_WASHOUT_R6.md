# UFOTRI 4.0（1993）P0 R6 — 原始输入卡、降雨清除与气象单位审计

**版本依据**：目标为 W. Raskob，KfK 5194，1993 年 UFOTRI 4.0，而非 1990 年 KfK 4605 或仓库内部 V4 阶段。此次审计逐页核对 [KIT 官方 KfK 5194 PDF](https://publikationen.bibliothek.kit.edu/270034158/3813483) 的印刷页 35、46–49、66–67。1990、1991 相关输入格式的完整等价性仍待另行审查。

全部输入约束另见 [R6 机器可读证据](primary_source_input_washout_r6.yaml)。本文件**不是已实现的输入解析器**，也不授权把 1993 默认值替换现有 KfK4605 运行默认值。

## 1. 原始输入结构与排序

原始第 35 页（PDF 零基 44）区分三组必须输入的卡：`METEOZON`、`SOURCE` 和 `END`。可选输入包括 `PRINTOUT`、`POLGRID`、`ISOTOPE`、`METEOROL` 和 `TRIDAT`。

手册明确给出了四类顺序约束：

1. 如使用 `ISOTOPE`，它必须先于 `SOURCE`；
2. 如使用 `POLGRID`，它必须先于 `METEOZON`；
3. 如使用 `PRINTOUT`，它必须先于 `POLGRID`；
4. `END` 必须是 UFOTRI 专有输入的最后一组；若使用 `TRIDAT` NAMELIST，则放在 `END` 之后。

这些是**有条件的偏序规则**，不是要求所有可选组必定存在，更不是现代 CUFOTRI 必须复刻 FORTRAN 文本语法。P1 可建立结构化适配器，但应能标注合法/不合法历史配置。

[官方印刷 p.35](https://publikationen.bibliothek.kit.edu/270034158/3813483#page=45)。

## 2. HT/HTO 顺序、沉降与两条湿清除分支

KfK 5194 §7.3.3，印刷 pp.46–47（PDF 零基 55–56），`ISOPAR` 中 `NABL=2`，核素次序必须是 **HT 在前，HTO 在后**。对应历史 `VA(NN)` 默认沉降速度为 HT `0.0005 m/s`、HTO `0.005 m/s`，`CORRVA` 默认 `[1,1]`。它们只是原版的历史参数，不能无条件覆盖当代模型的受体和下垫面沉降输入。

| 历史 `IWASH` 模式 | 1993 印刷原文行为 | 历史参数 |
|---|---|---|
| **0：默认** | 按三个雨强等级使用清除系数及相对降雨持续时间 | `IREGGR=[100,300]`，以 0.01 mm/h 编码，对应 **1、3 mm/h** 两个分档界 |
| **1：可选** | `XLAM(NN)=AWASH(NN)*I**BWASH(NN)`，其中 `I` 用 mm/h | HT 的 `AWASH/BWASH=[0,0]`，HTO 为 `AWASH=9×10⁻⁵`、`BWASH=0.6` |

默认 `IWASH=0` 下，按三档排列的 HTO 清除系数 `AMDA(HTO,IR)` 分别为 `6×10⁻⁵`、`1×10⁻⁴`、`4×10⁻⁴ s⁻¹`；HT 对应系数为零。HTO 三档 `REGTIM`（降雨相对持续时间）分别为 `0.50, 0.75, 0.72`，HT 三档为零。

**关键纠正**：不能把 §5.3.3 Eq.(20) 中的 `AW=9×10⁻⁵, BW=0.6` 理解为原版默认 `IWASH` 分支。两条模式共存，但**默认分档模式与幂律可选模式有不同的数组、单位和持续时间控制**；后续 P1/P4 必须进行显式模式选择。

[原始印刷 p.46](https://publikationen.bibliothek.kit.edu/270034158/3813483#page=56) · [p.47](https://publikationen.bibliothek.kit.edu/270034158/3813483#page=57)。

## 3. `METPAR` 的缩放单位与风场模式

KfK 5194 §7.3.4，印刷 pp.48–49（PDF 零基 57–58）：

| 参数 | 印刷默认值 | 真实含义和风险 |
|---|---:|---|
| `METIN` | 0 | 0：从文件读取变化气象；非零：单个固定气象情景。§7.4.9 对固定参数特指 `METIN=1` |
| `NOSHFT` | 2 | 0：全部排放相同风向；1：每次排放取起始风向；**2：考虑排放过程逐小时风向变化** |
| `IWNDR` | 360 | 风向（度） |
| `IWNDG` | 500 | 原始单位为 **0.01 m/s**，所以 500 对应 **5 m/s** |
| `IDIKAT` | 4 | 稳定度/扩散类别 D，类别 1–6 对应 A–F |
| `IREGN` | 0 | 原始单位为 **0.01 mm/h** |
| `HGHT` | 50、100、180 m | `σ` 参数的三个高度类别 |
| `MIXLH` | 1600、1200、800、560、320、200 m | 稳定度 A–F 的混合层高度 |
| `WPE` | 0.07、0.13、0.21、0.34、0.44、0.44 | A–F 的风速廓线幂指数；本轮不认定是 1993 新增 |

如果未来将外部 ERA5/站点风速（m/s）和降雨（mm/h）接入这一历史配置，必须先完成**明确的物理单位转换契约**；不能认为 `IWNDG=500` 等价于现代数据值 500 m/s。

[原始印刷 p.48](https://publikationen.bibliothek.kit.edu/270034158/3813483#page=58) · [p.49](https://publikationen.bibliothek.kit.edu/270034158/3813483#page=59)。

## 4. 固定气象模式及其测试属性

1993 §7.4.9，印刷 p.66（PDF 零基 75）明确把固定气象计算列为**仅推荐用于测试**的模式。此模式使用：

| 历史变量 | 默认值 | 原文条件 |
|---|---:|---|
| `IRFIX` | 0 | 常规程序计算再释放；1 为固定速率路径且有“需要修改程序”的提示 |
| `REFEST` | 5.0 | 固定再释放率，%/h |
| `ITEMPE` | 1000 | 原文单位为 °C ×100，换算为 10°C |
| `ISTRBE` | 100 | 辐射平衡，原文写 Watt；不能自动改写为 W/m² |
| `RELFA` | 0.5 | 原文标注“相对湿度，percent”，但默认值 0.5 与常见百分比/分数习惯存在歧义 |

**RELFA 是待解决的来源单位问题。** 不能仅凭原文把它当作 0.5% 或 50% 并写入科学求解器。

[原始印刷 p.66](https://publikationen.bibliothek.kit.edu/270034158/3813483#page=76)。

## 5. `KAUSDR` 属于诊断输出，不属于物理机制开关

§7.4.10，印刷 p.67（PDF 零基 76）给出 `IFACHS=28`、`IEINR(1..4)=[6,8,12,16]`、`IZUAUS=0`、`KAUSDR(1..12)=12*0`。其中 `KAUSDR(4)` 控制剂量打印、`(5)` 控制食品限制、`(7)` 控制转移系数、`(8)` 控制再释放面源/强度、`(9)` 控制土壤植物、`(12)` 控制长期食入剂量。

因此它们是**原版 FORTRAN 打印开关**，不等于这些物理分支是否启用，也不能当作“模型已有原始数值输出”的证据。

[原始印刷 p.67](https://publikationen.bibliothek.kit.edu/270034158/3813483#page=77)。
