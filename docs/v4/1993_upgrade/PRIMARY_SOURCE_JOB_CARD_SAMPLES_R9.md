# UFOTRI P0 R9 — 历史作业输入示例与固定列卡片一致性审计

本次在 [KfK 4853（1991）](https://publikationen.bibliothek.kit.edu/270030531/3813429) **Table 3 印刷 p.43（PDF 零基 50）** 以及 [KfK 5194（1993）](https://publikationen.bibliothek.kit.edu/270034158/3813483) **Table 5 印刷 p.82（PDF 零基 91）** 中找到了真正印在手册里的 UFOTRI **Job Control 输入示例**。已对照两版各自 `K1.2 / K2.2 / K2.3` 字段说明：1991 §3.2.1–3.2.2 pp.11–14（PDF0 18–21）、1993 §7.2.1–7.2.2 pp.37–40（PDF0 46–49）。结构化证据见 [R9 注册表](primary_source_job_card_samples_r9.yaml)。

**证据级别**：这是 **扫描印刷的示例 JCL/输入卡片**，不是保留原始 ASCII 字节/列位置的 FORTRAN 输入文件，也不是成功运行原版 UFOTRI 的日志。表中短 token 序列仅用来复核数字个数与来源，不准根据空格自动恢复固定列。

## 1. SOURCE K2.2：示例与两版文字说明都有未解释余量

| 文献 | K2.2 说明页所印 `FORMAT` | 同版示例（可见 token） |
|---|---|---|
| 1991 KfK4853 §3.2.2 p.14 / Table 3 p.43 | `A8,2X,3I10,F10.2` | `FKxy 1 0 0` |
| 1993 KfK5194 §7.2.2 p.40 / Table 5 p.82 | `A8,2X,2I10` | `FKxy 1 0 0` |

**双版文字定义相同**：`UNFNAM, NPHMAX, IPZ`，即一个名称和两个有名整数。两份示例的来源卡行可见 **三个**类似整数的 token；即使 1993 说明页只有 `2I10`，印刷示例也不能直接按两个整数无歧义解释。不能由此断言第三个零是哪个隐含物理参数、是否在 FORTRAN READ 列表中，甚至是否是印刷遗留内容。保留 `SRC-R9-01=SOURCE_LIMITED`，无原始字节及代码不写解析器。

两版示例后面的 `K2.3` 均可见 `1, 20, 0.000E0, 0.000E0, 0.000E0`，与 `2I10,3E10.3` 对应五个已命名阶段字段；但它仍不能证明可运行的原版结果。`QH` 在原手册中为 **cal/s 热释放率**，不可与独立的 `Q1` 放射性源强混同。

## 2. METEOZON K1.2：示例数字相似不等于相同列语义

1991 Table 3 与 1993 Table 5 都可见 `KARLSRHE 1 1 0 1 2 10` 这一示例 token 序列，随后各有独立的 `4020` 行。两版说明页均印 `1X,A8,1X,2I10,5I5`，所以除站名外理论上有**七个数值栏位**；扫描样例仅能清楚分辨**六个非空数字 token**，意味着不能由示例的空格压缩版本明确判断哪个 I5 为空白或取隐含值。

更重要的是，R8 已确认**1991 末三个 I5 的印刷描述为 `IBEWE/IRAU/IHOM`，1993 则是 `IRAU/IHOM/IBEWE`**。这说明同样的可见数字在两个版本下可能涉及不同位置。此次不把 `4020` 推定为某个绝对气象日期或适用时钟，其语义需结合实际 `LWOPT=1` 的原始卡读取及气象文件核对。

## 3. 未在原始扫描示例中解决的问题

- 两版 SOURCE 说明均**提及** `K2.4`，但被核对的正文页及示例没有给出可以复核的 `K2.4` 完整定义；保持 `UNKNOWN`。
- 示例属于 JCL 中的多行输入，不是独立给出的准确列边界原始数据文件。任何语法解析器或额外的源强字段都需要原版 `READ/FORMAT` 代码、原始卡字节与一组原始运行记录交叉证实。
- 两版 `POLGRID/ISOTOPE/SOURCE/METEOZON` 示例高度相似，**只能说明手册示例的继承**，不能声称程序从 1991 到 1993 输入格式完全没变。

## 4. 交付范围和科学门槛

新增机器可读 `R9-SAMPLE-01..05`、五条风险 `SRC-R9-01..05` 及防误解析回归测试。R7、R8 已确认的历史字段与版本差异保持原值；**新增 R9 实例证据不能反推更改 1990 冻结求解器、1993 默认参数或现有科学容差**。

**P0=OPEN；1993_RUNTIME_MODE=NOT_ACTIVATED；ORIGINAL_EXECUTABLE_EQUIVALENCE=NOT_ESTABLISHED；EMPIRICAL_VALIDATION=NOT_ESTABLISHED**。此处完成的是印刷源文一致性审计，尚缺原始 FORTRAN 代码/真实字节输入、独立科学复核与数值验收。
